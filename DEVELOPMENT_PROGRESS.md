# Development Progress - Autonomous Enterprise Intelligence System

## Architecture Overview
- **Backend**: FastAPI + SQLAlchemy (Async) + Alembic + LangGraph + LangChain + Pydantic v2
- **Frontend**: React + TypeScript + Vite + Tailwind CSS v4 + Three.js / React Three Fiber + React Flow (@xyflow/react) + Framer Motion + Recharts + Zustand
- **RAG**: PDF/DOCX/TXT ingestion, chunking, hybrid retrieval (semantic + BM25 keyword), reranking, source citations
- **Memory**: 3-layer persistent memory (Short-term, Long-term, Episodic) in DB + optional Mem0
- **Protocols**: MCP tool registry & execution, A2A agent discovery & task protocol
